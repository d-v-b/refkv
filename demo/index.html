Image files to Zarr in the browser

Paste the URL of an image file, a Zarr or N5 store, or a .vzip archive. the format is detected from the file's first bytes, or the store's metadata. A service worker reads the input's structure with a few range requests, writes a vzip archive in memory (by spec/zarrify.md), and serves it as plain Zarr at a local URL that any Zarr viewer on this site can open: Neuroglancer, or for Sentinel-2 a map. Pixel data is read from the original only when a viewer asks for it. That link works only here; download the archive and host it, and the Neuroglancer link to its URL opens in any deployment of the viewer, with no service worker.

This Neuroglancer link opens only on this site, in a browser where this page has zarrified the file: the page's service worker answers its reads. To share a link, download the .vzip, put it on a server that allows cross-origin reads (CORS), and open its URL here. The link then names the archive (<archive url>|vzip:<path>|zarr3:), which any deployment of the Neuroglancer fork opens. The archive refers to the original's bytes by URL, so it stays small, and pins each source's size.
